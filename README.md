# Customer Churn Prediction using Machine Learning

## Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. This project uses Machine Learning to predict whether a customer is likely to leave (churn) or stay based on customer information such as tenure, monthly charges, contract type, payment method, and internet services.

The project demonstrates the complete machine learning workflow, including data preprocessing, feature engineering, model training, evaluation, feature importance analysis, and customer prediction.

## Objectives

- Predict whether a customer will churn.
- Compare the performance of multiple machine learning algorithms.
- Identify the most important factors influencing customer churn.
- Build a complete end-to-end classification project.

## Machine Learning Algorithms

- Logistic Regression

- Random Forest Classifier

## Project Workflow

1. Import libraries
2. Load dataset
3. Data exploration
4. Data cleaning
5. Handle missing values
6. Encode categorical features
7. Split features and target
8. Train-test split
9. Feature scaling
10. Train multiple machine learning models
11. Evaluate model performance
12. Compare model accuracy
13. Feature importance analysis
14. Predict churn for new customers

## Results

The Random Forest model achieved the best performance with an accuracy of approximately **82%**.
